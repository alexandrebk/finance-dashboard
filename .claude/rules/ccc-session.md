## Available Skills

### Pack (ccc-pack)

- **accessibility-auditor**: Audits Rails views for WCAG 2.1 AA and RGAA compliance. Default mode reviews modified files (git diff). Pass one or more file paths to audit specific files. Reports issues by severity then proposes and applies fixes.
- **active-admin**: Active Admin development for Rails
- **cascade-feature-pull-request**: Crée une cascade de PR pour des branches stackées sur un projet CapSens : une branche conflicts/<branche> par branche, mergée sur la branche de conflit précédente PUIS sur la base (ex. staging), avec des PR conflict→conflict (l'intranet retargette vers la base au merge du parent). Titre de PR = nom de branche, assignee = toi, reviewer + lien Trello configurés une fois et mémorisés. La skill s'arrête à chaque conflit pour que tu le résolves, tu pushes, puis elle crée la PR. Déclencher quand l'utilisateur dit "crée les PR en cascade", "cascade de conflits", "PR en cascade pour 3727/3728/3729", "prépare les branches conflicts/ et les PR", "create cascade PRs", "stacked conflict PRs".

- **code-review**: Code review on the current local git diff for Rails projects. Finds real bugs and verifies conformance to the spec described in the commits. Does NOT review style, lint, or naming conventions. Flags security issues only for major, confirmed vulnerabilities. Produces a .reviews/<branch>/<YYYYMMDD>_<HHMMSS>.md snapshot per iteration, stamped with the HEAD commit SHA, and a score out of 10. Use when the user says "review", "do a review", "review my PR", "code review", "look at my changes", "analyse my diff", "check my code", "what do you think of my changes", or runs /code-review. Also use when the user asks for a review without specifying a format.

- **commit**: Create a commit or an atomic commits plan from staged/unstaged changes, following the commit convention.
- **dream**: [experimental] Digest recent sessions — extract learnings, update rules/memory, suggest permissions. First run sets up required hooks automatically.
- **figma-mcp**: Maintains and repairs access to the Figma MCP server. Use when a figma.com URL appears in the conversation, when a Figma MCP tool call fails / times out / is unavailable, or when the user asks to (re)connect Figma ("reconnecte Figma", "le MCP Figma plante"). Handles reconnection (claude mcp add) and the required tool permissions. The actual design read/write is performed by the Figma plugin's own skills (figma-use, figma-generate-design) — this skill only keeps the connection alive and ensures permissions.

- **find-session**: Retrouver une session Claude Code perdue dans ~/.claude/projects en cherchant par mot-cle et fenetre temporelle. Utiliser quand l'utilisateur dit 'retrouve la conv', 'quelle session', 'find session', 'j'ai perdu la conv', 'cetait quel id', ou demande de localiser une discussion passee par sujet.
- **gh-review-triage**: Triage pending PR reviews for a GitHub repo. Detects dependency chains, ghost blockers, and outputs a prioritized review order.
- **lemonway-kyc-update**: Implement the Lemonway KYC Update integration on a crowdinvest Rails platform — recurring KYC re-verification with status detection, BO visibility, BO + FO banners and recertification emails. The epic is split into 4 independent steps; this skill orchestrates whichever step is being worked on. Use when implementing or extending any step of the KYC Update epic.
- **mangopay-identity-verification**: Replace a CapSens Rails platform's in-app MangoPay KYC (and, for legal users, UBO) document upload with MangoPay's hosted identity verification (IDV), rolled out behind a per-profile feature switch so it can be tested in production while everyone else keeps the current flow. Trigger when the user asks to "brancher l'IDV MangoPay", "passer à la vérification d'identité MangoPay", "remplacer le KYC par le parcours hébergé MangoPay", "mettre en place MangoPay identity verification", or refers to the hosted verification / IDV flow. Also covers MangoPay's second wave (from 31 Oct 2026): hosted verification of a legal user's PSCs — Persons with Significant Control, i.e. the beneficial owners (UBO) and legal representative — where a company is KYC-valid only once its session and every declared PSC are validated. Trigger too when the user asks to "ajouter les PSC / bénéficiaires effectifs", "brancher la vérification des UBO MangoPay", or "gérer les bénéficiaires effectifs des personnes morales". The skill audits the target, resolves the structural decisions with the developer, and writes an implementation plan tailored to the platform.

- **multi-wallet-refactor**: Refactor a CapsEns crowdfunding Rails app to the Lemonway V3 multi-wallet model: one wallet per investor account with per-subscription escrow, single project wallet on the project owner, no SPV onboarding, no dual-wallet flag, no V2 tech wallets. Trigger when the user asks to "passer en multi-wallet", "appliquer le refactor multi-wallet", "préparer la plateforme pour la MEP multi-wallet", or refers to Trello card #2538 or its replicas. The skill inspects the target codebase, detects which legacy patterns are present, adapts the vocabulary (Profile / ProjectOwner / Project / Subscription may be renamed Investor / Borrower / Loan / Investment depending on the platform), and writes an implementation plan tailored to the target.

- **rails-tdd**: Use when implementing any feature or bugfix in Rails, before writing implementation code
- **rails-upgrade**: Upgrade a Rails application one minor version at a time, with selective file merging and safe commit strategy
- **resolve-conflicts**: Resolve merge conflicts against a target branch following the CapSens convention — an isolated conflicts/ branch for staging (default), or in-place for other targets (e.g. master before a deploy).
- **security-audit**: Comprehensive security audit of a Rails application. Scans the repo for the main OWASP vulnerability classes (SQL injection, mass assignment, broken authorization / IDOR, CSRF, command injection, SSRF, open redirect, hardcoded secrets, unsafe file upload / path traversal, unsafe deserialization, and XSS). For every Critical and High finding it re-challenges the candidate with adversarial sub-agents to prove it is actually exploitable and builds a concrete reproduction scenario that runs on the local dev environment. Trigger when the user asks to "auditer la sécurité", "faire un audit de sécu", "chercher les failles de sécurité", "security audit", or runs /security-audit.

- **signlift-integration**: Integrate Signlift electronic signature into a CapsEns Rails app, most often replacing Universign. Trigger when the user asks to "intégrer Signlift", "migrer de Universign vers Signlift", "brancher la signature électronique", "remplacer Universign", or refers to a Signlift integration card — including a single step card of a Signlift epic (configuration, tunnel de signature, nettoyage Universign, balise Doclift). The skill first checks that https://doc.signlift.eu has not drifted from the facts it encodes, asks the user to add the required environment variables, inspects the target codebase to detect the existing signature provider and the local service layer (dry-monads workflows vs dry-transactions, ActionCable tunnel or not, contract generator), installs the signlift-ruby gem, adapts the application layer, and writes the recovery matrix that no snippet can supply. Ends by offering a smoke-test plan against the sandbox.

- **stimulus-migration**: Migrate plain JavaScript in a Rails app to Stimulus controllers. Audits the app for migratable JS (inline <script> in views, legacy app/assets/javascripts jQuery, ad-hoc app/javascript modules, data-behavior dispatchers), classifies each unit by how cleanly it maps to a Stimulus controller, then creates the controllers, wires the data-* attributes into the ERB, and removes the old JS. Bootstraps Stimulus if absent. Trigger when the user asks to "migrer le JS vers Stimulus", "passer ce JS en Stimulus", "créer un controller Stimulus pour ...", "migrate JS to Stimulus", or runs /stimulus-migration.

- **tech-watch**: [experimental] Scan the latest tech news, trending repos, security advisories, and developer ecosystem updates. Use when the user wants a tech digest or asks about recent developments. Optionally filter by topic, time period (day/week/month), density (short/medium/large), and language.
- **trello-feature-breakdown**: Break a feature down into Trello cards, lot by lot ("lot 1", "lot 2"...), with one epic per lot, a consistent label scheme, and an optional estimation pass that recomputes day estimates in epic titles from scrum points written in sub-card titles. Trigger when the user asks to "découper une feature en cartes Trello", "créer les cartes du lot N", "préparer le board pour la feature X", or "recalculer les estimations des epics".

- **xss-security-audit**: Perform comprehensive XSS security audits of the Rails application. Analyzes codebase for unsafe HTML rendering, URL handling, and JavaScript injection patterns.
